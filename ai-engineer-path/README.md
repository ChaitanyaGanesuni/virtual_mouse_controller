# AI Engineer Path

A single-file interactive course that takes a complete beginner from Python to building, fine-tuning, serving and operating LLM systems: 552 concepts in 20 stages, taught one concept at a time.

Open `index.html` in a browser, or use the published artifact.

## How each concept is taught

Every concept has the same seven steps:

1. **Idea**: definition, why it exists, an analogy, a banking example, and where it shows up in AI engineering
2. **How it works**: an interactive, step-by-step visual
3. **Math & internals**: formulas, derivations and what happens inside
4. **Code**: runnable Python explained line by line (Python runs in the browser through Brython in a Web Worker, with a time limit for runaway loops)
5. **Pitfalls & production**: common mistakes, trade-offs and production use
6. **Practice**: an exercise checked by real tests against your code
7. **Check**: 5 questions with new numbers each attempt; 4 correct masters the concept and unlocks the next

Narration is available in English, Telugu and Hindi (browser speech). Progress is saved in the browser (`localStorage`, key `aieng.v1`).
