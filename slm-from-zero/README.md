# SLM From Zero

A beginner-friendly companion to the SLM Learning Lab: 15 five-minute chapters that explain how a small language model is built using everyday analogies (a phone keyboard, Lego bricks, a loan committee, a factory, a restaurant).

Each chapter has four steps (Imagine, Play, Real life, Quick check) and can be narrated in English, Telugu or Hindi using the browser's built-in voices. Open `index.html` in any browser; no build step or GPU needed.
