# SLM Learning Lab

An interactive, single-file lab for learning how a Small Language Model is built, from basic ideas to deployment.
Open `index.html` in any browser. It needs no build step and no GPU.

- Stage 0 (Understanding Language Models) is fully built: AI map, a working n-gram learner, the sentence journey through a model, the SLM/LLM size explorer, CPU code, an exercise and a 5-question assessment.
- Later stages unlock when you score 4/5 or better on the previous assessment. Progress is saved in your browser.
