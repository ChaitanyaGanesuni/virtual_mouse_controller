# SLM Learning Lab

An interactive, single-file lab for learning how a Small Language Model is built, from basic ideas to deployment.
Open `index.html` in any browser. It needs no build step and no GPU.

- Stages 0 (Understanding Language Models), 1 (Mathematical Foundations), 2 (Tokenization) and 3 (Word Embeddings) are fully built. Stage 1 covers tensors, the dot product, animated matrix multiplication, softmax, cross-entropy, derivatives, gradient descent on a loss landscape and step-by-step backpropagation, each with a "predict first" question.
- Later stages unlock when you score 4/5 or better on the previous assessment. Progress is saved in your browser.
